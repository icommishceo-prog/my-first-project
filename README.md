# Jett Medical Company Website

A static marketing website for **Jett Medical Company**, a medical supply and equipment provider in Bessemer, Alabama specializing in post-injury recovery support.

## Pages

- `index.html` — Home: overview, services snapshot, location card, CTA
- `about.html` — About the company, values, mission
- `services.html` — Medical & surgical supplies, mobility equipment, in-home setup, repairs, financing
- `contact.html` — Address, contact form, embedded map

## Stack

Plain HTML, CSS, and JavaScript — no build step required.

## Running locally

Open `index.html` directly in a browser, or serve the directory with any static server, e.g.:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.
