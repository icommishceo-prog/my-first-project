# Wallpaper

Drop a file named **`bliss.png`** here and `install-theme.sh` will use it as the
desktop background.

We deliberately do **not** ship Microsoft's copyrighted "Bliss" photograph
(the famous green hills). Options:

- Supply your own image (rename it `bliss.png`).
- Use a Creative Commons / public-domain green-hills photo that evokes the look.
- Let the installer generate a Bliss-*style* gradient placeholder automatically
  (it does this when no `bliss.png` is present and ImageMagick is installed).

Keep it `1920x1080` (or your VM's resolution) for best results.
